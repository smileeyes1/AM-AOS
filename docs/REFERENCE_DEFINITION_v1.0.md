# AM-AOS — Reference Definition v1.0

**Status: REFERENCE / FROZEN**

AM-AOS (Adaptive Mission Assurance Operating System) is an adaptive, assurance-governed mission operating system that converts goals into executable and verifiable tasks, manages a network of agents, tools, and resources within controlled authority boundaries, and operates through a continuous loop of planning, execution, monitoring, verification, diagnosis, repair, and replanning. It evaluates evidence and evidence sufficiency alongside outcomes, prevents authority-boundary violations, and maintains an auditable record of decisions, actions, and evidence. Material changes are subject to adversarial, failure, and regression testing before adoption. Adaptation is permitted in strategy and execution, but not in the mission goal, constitutional constraints, or authority boundaries.

## Required operational transformation

Every normative statement in this definition must map to:

1. Component
2. Contract
3. Invariant
4. Acceptance criterion
5. Failure test
6. Evidence artifact
7. Audit event
8. Regression protection

The reference definition is frozen. Changes require an explicit versioned change process and must not silently redefine the constitutional baseline.
